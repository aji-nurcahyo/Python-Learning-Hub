# Atribusi

Fondasi arsitektur dan sistem komponen diadaptasi dari **Pengkom Informatika ITERA**:
https://github.com/informatika-itera/pengkom
Commit referensi: `30ce99f8a4a4bed7e9dc7d801a0030da949df3ab`.

`src/ui/highlight.ts` dan `src/ui/Math.tsx` berasal dari proyek tersebut.
Struktur tema, shell, registry, layout, dan pipeline kode mengambil inspirasi dari implementasinya.
Salinan pemberitahuan lisensi upstream dipertahankan tanpa perubahan di `LICENSE.upstream`.

Pustaka: React (MIT), Reveal.js (MIT), Vite (MIT), TypeScript (Apache-2.0), Shiki (MIT), KaTeX (MIT).
Font Google Sans Flex dan Google Sans Code didistribusikan melalui Fontsource; lihat lisensi font dalam paket masing-masing.
Pemberitahuan lisensi dependensi juga tersedia di dalam paket terpasang.

Materi Pertemuan 9 dan 10 berasal dari proyek lokal pengguna, tetap dipertahankan.
Lisensi MIT upstream tidak dimaksudkan untuk mengubah status kepemilikan materi lokal tersebut.
