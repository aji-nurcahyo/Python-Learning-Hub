# Latihan Terarah: Latihan Terarah: Pemetaan Himpunan Lokasi Sinyal (Set & Dict)
Estimasi Waktu: 20 menit

## Instruksi:
1. Diberikan daftar dictionary record sensor yang memuat kunci "lokasi".
2. Gunakan tipe data set untuk mengekstrak daftar nama gedung/lokasi unik tanpa duplikasi.
3. Cetak himpunan lokasi unik dan hitung total titik pemancar.

## Tips:
Set secara otomatis membuang duplikasi ketika Anda menambahkan elemen menggunakan method add() atau set comprehension.
