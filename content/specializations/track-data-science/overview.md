# Track Spesialisasi: Data Science & Visualization
> **Eksplorasi, Manipulasi Tabular & Visualisasi Analitik**
*Dari data mentah menjadi wawasan analitik yang berdampak*

## Profil Sasaran
Data Analyst, Data Scientist, Riset Kuantitatif, Analis Bisnis

## Deskripsi
Jalur spesialisasi untuk mengolah, membersihkan, dan menganalisis dataset berdimensi besar menggunakan pustaka standar industri seperti NumPy, Pandas, Matplotlib, dan Seaborn.

## Modul Silabus Terstruktur
### Modul 1: Foundations of Data Arrays (NumPy) [Specialization]
Operasi matriks berkinerja tinggi, vektorisasi, dan broadcasting matematis.

### Modul 2: Data Wrangling & Cleaning (Pandas) [Specialization]
Transformasi DataFrame, penanganan missing values, pengelompokan groupby, dan pivot tables.

### Modul 3: Exploratory Data Analysis (EDA) [Specialization]
Identifikasi pola statistik, outlier detection, dan korelasi antar variabel.

### Modul 4: Publication-Ready Visualizations (Matplotlib & Seaborn) [Specialization]
Merancang grafik statistik profesional, multi-panel charts, dan visualisasi distribusi.

### Modul 5: Capstone: End-to-End Analytics Report [Advanced Project]
Pipeline pengolahan dataset telekomunikasi dan ekonomi publik dari ingestion hingga dashboard laporan.
