# Track Spesialisasi: IoT, Signal Processing & Telecommunications
> **Analisis Sinyal Digital, Pengukuran RSRP, Sensor Data & IoT Protocols**
*Pengolahan sinyal, data telekomunikasi nirkabel, dan perangkat terhubung*

## Profil Sasaran
Teknik Telekomunikasi, IoT Engineer, RF Engineer, Peneliti Sinyal

## Deskripsi
Jalur spesialisasi telekomunikasi & IoT: pengolahan sinyal diskrit (SciPy signal), analisis data propagasi sinyal seluler (RSRP, RSRQ, SINR), protokol MQTT, dan visualisasi pemetaan sensor.

## Modul Silabus Terstruktur
### Modul 1: Telemetry Data Structures & Sensor Records [Core Prerequisite]
Pemanfaatan dictionary dan tuple untuk data geolokasi (lat, lon) dan log pengukuran sensor.

### Modul 2: Cellular Signal Processing (RSRP/RSRQ Analysis) [Core Prerequisite]
Klasifikasi kualitas sinyal radio 4G/5G, moving average filtering, dan deteksi zona blindspot.

### Modul 3: Digital Signal Processing Fundamentals (SciPy) [Specialization]
Transformasi Fourier (FFT), spectral analysis, dan perancangan filter digital.

### Modul 4: IoT Protocols & Telemetry Streaming (MQTT) [Specialization]
Publish-subscribe messaging untuk telemetri sensor edge perangkat nirkabel.

### Modul 5: Capstone: Sistem Monitoring Kualitas Jaringan Telekomunikasi [Advanced Project]
Dashboard analitik pemrosesan log pengukuran sinyal stasiun pemancar dengan metrik statistik komprehensif.
