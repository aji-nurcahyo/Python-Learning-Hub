PENGANTAR KOMPUTASI · PYTHON

Mengapa fungsi?

  • Reusable: dipakai ulang tanpa menyalin kode.
  • Testable: mudah diuji untuk input berbeda.
  • Readable: nama fungsi menjelaskan tujuan.
  • Maintainable: perubahan cukup dilakukan di satu tempat.
PENGANTAR KOMPUTASI · PYTHON

Anatomi fungsi Python

def luas_persegi_panjang(panjang, lebar):
    """Hitung luas dari panjang dan lebar."""
    return panjang * lebar

hasil = luas_persegi_panjang(6, 4)
print(hasil)  # 24

Nama, parameter, docstring, badan fungsi, return, dan pemanggilan.

PENGANTAR KOMPUTASI · PYTHON

Parameter, argumen, default

def tampilkan_sinyal(rsrp, satuan="dBm"):
    return f"{rsrp} {satuan}"

print(tampilkan_sinyal(-91))
print(tampilkan_sinyal(-88, satuan="dBm"))

Parameter berada di definisi; argumen diberikan saat pemanggilan.

PENGANTAR KOMPUTASI · PYTHON

Print vs return

def versi_print(x):
    print(x * 2)

def versi_return(x):
    return x * 2

hasil = versi_print(5)   # mencetak 10
print(hasil)             # None
print(versi_return(5) + 3)  # 13

return memungkinkan hasil digunakan oleh proses lain.

PENGANTAR KOMPUTASI · PYTHON

Function design: input – proses – output

  • 1. Rumuskan apa yang harus dikerjakan.
  • 2. Tentukan input dan tipe datanya.
  • 3. Tentukan output, termasuk kondisi khusus.
  • 4. Pilih nama fungsi yang menggambarkan kegunaan.
  • 5. Uji fungsi dengan kasus normal dan batas.
Contoh kontrak: rata_rata(data) → float atau None saat data kosong.
PENGANTAR KOMPUTASI · PYTHON

Studi kasus: rata-rata RSRP

def rata_rata(data):
    """Kembalikan rata-rata, atau None bila kosong."""
    if not data:
        return None
    return sum(data) / len(data)

print(rata_rata([-80, -100, -90]))  # -90.0
print(rata_rata([]))  # None
PENGANTAR KOMPUTASI · PYTHON

Studi kasus: klasifikasi sinyal

def kategori_rsrp(rsrp):
    """Kategori ilustratif RSRP untuk latihan."""
    if rsrp >= -90:
        return "Baik"
    elif rsrp >= -105:
        return "Sedang"
    return "Buruk"

print(kategori_rsrp(-110))  # Buruk

Ambang ini untuk pembelajaran, bukan standar universal jaringan.

PENGANTAR KOMPUTASI · PYTHON

Scope: variabel lokal dan global

nilai = 10  # global

def hitung():
    nilai = 20  # lokal
    return nilai + 5

print(hitung())  # 25
print(nilai)     # 10

Utamakan parameter dan return daripada mengubah variabel global.

PENGANTAR KOMPUTASI · PYTHON

Apa itu module?

  • Module adalah berkas .py berisi fungsi, variabel, atau kelas.
  • Kode dapat dipisah menurut tanggung jawab.
  • Module dipanggil dari file lain menggunakan import.
  • Gunakan if __name__ == "__main__": untuk kode demo yang tidak berjalan saat import.
PENGANTAR KOMPUTASI · PYTHON

Membuat modul sendiri

# file: statistik.py
def rata_rata(data):
    """Hitung rata-rata data numerik."""
    return sum(data) / len(data) if data else None

# file: main.py
from statistik import rata_rata
print(rata_rata([1, 2, 3]))  # 2.0
PENGANTAR KOMPUTASI · PYTHON

Docstring yang baik

def konversi_suhu(celsius):
    """Konversi suhu dari Celsius ke Fahrenheit.

    Args:
        celsius (float): Suhu dalam Celsius.
    Returns:
        float: Suhu dalam Fahrenheit.
    """
    return celsius * 9 / 5 + 32

print(konversi_suhu.__doc__)

Docstring berbeda dari komentar biasa: dapat diakses melalui help().

PENGANTAR KOMPUTASI · PYTHON

Menghindari efek samping saat import

def hitung(x):
    return x * 2

if __name__ == "__main__":
    print(hitung(4))
    assert hitung(4) == 8

Bagian demo hanya dijalankan ketika file dibuka sebagai program utama.
