List: urutan data yang dapat diubah

nilai = [-82, -107, -95]
nilai.append(-89)
nilai[1] = -102
print(nilai[0])
print(nilai[-1])
print(len(nilai))

List cocok untuk koleksi terurut, termasuk data pengukuran.

Tuple: data tetap

koordinat = (-5.36, 105.31)
lat, lon = koordinat
print(lat, lon)
# koordinat[0] = -5.4  # TypeError

Tuple tidak bisa dimodifikasi setelah dibuat (immutable).

PENGANTAR KOMPUTASI · PYTHON

Dictionary: pasangan key–value

sensor = {"id": "S01", "lokasi": "Gedung A", "rsrp": -82}
print(sensor["id"])
print(sensor.get("rsrq", "tidak tersedia"))
sensor["rsrp"] = -80
print(sensor.items())

Dictionary cocok untuk satu record dengan atribut bernama.

PENGANTAR KOMPUTASI · PYTHON

Set: kumpulan nilai unik

lokasi = ["Gedung A", "Gedung B", "Gedung A"]
unik = set(lokasi)
print(unik)  # urutan tidak dijamin
print("Gedung B" in unik)

Set menghilangkan duplikasi dan mendukung uji keanggotaan.

PENGANTAR KOMPUTASI · PYTHON

Pilih struktur yang tepat

  • List: deretan RSRP berdasarkan urutan pencatatan.
  • Tuple: koordinat tetap (lat, lon).
  • Dict: atribut satu sensor (ID, lokasi, nilai).
  • Set: nama lokasi unik tanpa duplikasi.
PENGANTAR KOMPUTASI · PYTHON

List comprehension

rsrp = [-82, -107, -95, -89]
lemah = [x for x in rsrp if x < -100]
selisih = [x + 100 for x in rsrp]
print(lemah)     # [-107]
print(selisih)   # [18, -7, 5, 11]

Gunakan jika transformasi dan filter sederhana tetap mudah dibaca.

PENGANTAR KOMPUTASI · PYTHON

Set dan dictionary comprehension

data = [
    {"id": "S01", "lokasi": "A", "rsrp": -82},
    {"id": "S02", "lokasi": "B", "rsrp": -107},
]
lokasi_unik = {x["lokasi"] for x in data}
rsrp_per_id = {x["id"]: x["rsrp"] for x in data}
print(lokasi_unik)
print(rsrp_per_id)
PENGANTAR KOMPUTASI · PYTHON

Pencarian linear (linear search)

def cari_sensor(data, id_sensor):
    for sensor in data:
        if sensor["id"] == id_sensor:
            return sensor
    return None

Memeriksa item satu demi satu; kompleksitas waktu O(n).

PENGANTAR KOMPUTASI · PYTHON

Cari data: contoh penggunaan

hasil = cari_sensor(pengukuran, "S02")
if hasil is None:
    print("Sensor tidak ditemukan")
else:
    print(hasil["lokasi"], hasil["rsrp"])

Gunakan data pengukuran dari slide awal serta definisi fungsi pada slide sebelumnya.

PENGANTAR KOMPUTASI · PYTHON

Mengurutkan dengan sorted()

nilai = [-82, -107, -95, -89]
print(sorted(nilai))
print(sorted(nilai, reverse=True))
print(nilai)  # tetap, tidak diubah

Nilai RSRP -82 dBm lebih besar daripada -107 dBm.

PENGANTAR KOMPUTASI · PYTHON

Sorting record berdasarkan key

data = [
    {"id": "S01", "rsrp": -82},
    {"id": "S02", "rsrp": -107},
    {"id": "S03", "rsrp": -95},
]
terbaik = sorted(data, key=lambda x: x["rsrp"], reverse=True)
print([x["id"] for x in terbaik])

Output: ["S01", "S03", "S02"].

PENGANTAR KOMPUTASI · PYTHON

Selection sort: algoritma manual

def selection_sort(data):
    hasil = data.copy()
    for i in range(len(hasil)):
        indeks_min = i
        for j in range(i + 1, len(hasil)):
            if hasil[j] < hasil[indeks_min]:
                indeks_min = j
        hasil[i], hasil[indeks_min] = hasil[indeks_min], hasil[i]
    return hasil

O(n²), digunakan untuk memahami mekanisme pengurutan.

PENGANTAR KOMPUTASI · PYTHON

Pencarian vs pengurutan

  • Linear search: mencari sebuah item pada data tidak terurut — O(n).
  • Selection sort: mengurutkan secara manual — O(n²).
  • sorted(): pilihan praktis untuk aplikasi Python sehari-hari.
  • Gunakan key=lambda ... untuk record dictionary.
