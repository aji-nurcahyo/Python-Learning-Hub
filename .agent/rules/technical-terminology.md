# Global Technical Terminology Rule

## Fundamental Principle
"Indonesian for explanations, English for established technical terminology."

Write all explanations, guidelines, assignments, and tutorials in natural, grammatical Bahasa Indonesia. Preserve established, internationally recognized English technical terms without translating them literally.

## Scope of Application
This rule strictly applies to:
- Python learning chapters (Foundations, Intermediate, Professional).
- AI & Machine Learning learning materials (Kecerdasan Buatan / Future AI modules).
- Interactive presentation slides (Reveal.js).
- Development Environment & Setup tutorials.
- Code walkthroughs, docstrings, and comments.
- Exercises, quizzes, and project assignments.
- Curriculum documentation and README files.

## Mandatory Terminology Standards
Always use the **Preferred** English term; avoid the literal Indonesian translation:

| Avoid (Dilarang) | Preferred (Wajib Digunakan) |
| :--- | :--- |
| Lingkungan pengembangan | Development Environment |
| Lingkungan pemrograman | Programming Environment |
| Lingkungan virtual | Virtual Environment |
| Penerjemah Python | Python Interpreter |
| Penyunting kode | Code Editor |
| Kamus Python | Python Dictionary / dictionary |
| Daftar Python | Python List / list |
| Pewarisan | Inheritance |
| Pengkapsulan | Encapsulation |
| Polimorfisme | Polymorphism |
| Pembelajaran mesin | Machine Learning |
| Pembelajaran mendalam | Deep Learning |
| Jaringan saraf tiruan | Artificial Neural Network |
| Pelatihan model | Model Training / Training |
| Penyetelan halus | Fine-Tuning |
| Penyebaran model | Model Deployment / Deployment |
| Penanganan pengecualian | Exception Handling |
| Penanganan kesalahan | Error Handling |
| Pengujian unit | Unit Testing |
| Cakupan pengujian | Test Coverage |
| Pemanggilan balik | Callback |
| Pengulangan asinkron | Asynchronous Execution |
| Manajemen dependensi | Dependency Management |

## Natural Indonesian Vocabulary Permitted
Standard Indonesian technical concepts that have natural academic and industry usage remain completely valid:
- `algoritma`, `variabel`, `parameter`, `perulangan`, `percabangan`, `pengujian`, `evaluasi`, `struktur data`, `konkurensi`, `masukan`, `keluaran`.

## Rules for Code and References
- Never alter Python syntax, built-in keywords (`def`, `class`, `yield`, `import`, etc.), standard library identifiers, or package names.
- Never alter original titles of external reference papers, books, or upstream license attribution.
